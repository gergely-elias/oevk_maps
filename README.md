## Országgyűlési egyéni választkerületek (OEVK) térképei
Ebben a repository-ban GeoJSON formátumú állományokba gyűjtve található meg a harmadik Magyar Köztársaság országgyűlési választásainak egyéni választókerületeit leíró adat.  

### Kapcsolódó változások idővonala

- 1990\. január 1-jén Szolnok megye neve Jász-Nagykun-Szolnok megyére változott. Bár az 1990-es országgyűlési választási adatokban a megye neve már Jász-Nagykun-Szolnokként szerepel, a megye azonosítója mégis (a régi, Szolnok elnevezésen alapuló) 16-os, Szabolcs-Szatmár-Bereg es Tolna megyék között jelenik meg. 1994-től Jász-Nagykun-Szolnok megye azonosítója már 11-es, Heves es Komárom-Esztergom között szerepel a kapcsolódó adatsorokban.

- 2011-ben az OEVK-k száma 176-ról 106-ra csökkent.

- 2020\. június 4-én Csongrád megye neve Csongrád-Csanádra változott.

- 2023\. január 1-én a megye megnevezést vármegyére módosították.

- 2024-ben az OEVK-k vármegyei eloszlása, valamint egyes OEVK-k határa megváltozott.

### Források

A 2011 előtti OEVK-kat leíró file-okért köszönettel tartozom Szabó Krisztiánnak, az Átlátszó adatújságírójának.

A 2011 utáni adatok forrása a Nemzeti Választási Iroda honlapja, a valasztas.hu.
